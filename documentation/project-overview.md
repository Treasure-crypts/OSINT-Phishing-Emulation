## Project Objective
To understand how publicly available information can be
collected and analysed using OSINT techniques.

## Project Activities
1. OSINT Footprinting

4. Email Header Analysis

## Safety Scope
This project uses fictional identities and synthetic data.
No real individuals will be targeted.
No phishing emails will be sent to real users.
No credentials will be collected.
